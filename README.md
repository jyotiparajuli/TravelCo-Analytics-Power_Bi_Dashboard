# TravelCo-Analytics-Power_Bi_Dashboard

## Project Overview

Interactive Power BI dashboard developed for travel business analysis. The dashboard helps stakeholders monitor bookings, revenue, customer ratings, destinations, and business performance through dynamic visualizations and insights.

## Features

* Interactive KPI cards
* DAX measures and calculations
* Dynamic slicers and filters
* Navigation buttons and page routing
* Business recommendation page
* Trend and performance analysis
* Cross-filtering visual interactions
* Responsive dashboard design

## Key Metrics

* Total Revenue
* Total Bookings
* Average Package Price
* Average Customer Rating
* Total Destinations

## Dashboard Pages

1. Executive Summary
2. Booking & Revenue Analysis
3. Customer Insights
4. Destination Performance
5. Business Recommendations

## Tools Used

* Power BI Desktop
* Power Query
* DAX
* Data Modeling
